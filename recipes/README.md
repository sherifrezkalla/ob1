## Which Recipe Should I Start With?

Pick based on your current bottleneck:

| If this sounds like you... | Start here | Why |
| --- | --- | --- |
| “Important context is trapped in old email.” | [Email History Import](email-history-import/) | Backfills historical decisions and commitments into searchable memory. |
| “I keep repeating work I already did in ChatGPT.” | [ChatGPT Conversation Import](chatgpt-conversation-import/) | Recovers prior AI conversations as reusable context. |
| “I capture notes but rarely review them.” | [Daily Digest](daily-digest/) | Builds a daily review loop automatically. |

### Recommended Install Order

- **Email-heavy workflow:** Email History Import → Daily Digest → ChatGPT Conversation Import
- **AI-heavy workflow:** ChatGPT Conversation Import → Daily Digest → Email History Import
- **Inconsistent review habit:** Daily Digest → ChatGPT Conversation Import → Email History Import

### 7-Day Starter Plan

1. Pick one recipe and implement it end-to-end.
2. Validate with one real question you couldn't answer quickly before.
3. Add Daily Digest to enforce a review cadence.
4. Add your third recipe only after the first two are stable in your routine.
